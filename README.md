# Netflix Content Analysis
## Research Question
What trends can be observed in Netflix movies and TV shows over time?

## Project Overview
This project explores the Netflix Movies and TV Shows dataset to identify patterns in content production, release years, content types, ratings, and geographical distribution.

The project demonstrates the use of data cleaning, exploratory data analysis (EDA), and visualization techniques to gain insights from entertainment industry data.

## Dataset Source
Netflix Movies and TV Shows Dataset

Source: Kaggle

This dataset is publicly available for educational and research purposes.

## Methods and Tools Used
### Programming Language

### Libraries

### Techniques
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization

## Visualizations
The project includes visualizations such as:
1. Netflix Content Added by Year
2. Distribution of Movies and TV Shows

## Key Findings
- Netflix content has increased significantly over recent years.
- Movies make up the majority of titles on the platform.
- Content originates from a diverse range of countries.
- Certain maturity ratings are more common than others.

## Limitation
The dataset represents Netflix content available at the time of collection and may not reflect current catalog changes.
